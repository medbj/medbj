# MENA Psychology

A calm, accessible educational reading site built with Astro, strict TypeScript, MDX content collections, plain CSS, and Pagefind. It generates a static `dist/` directory. The working title and sample content need human editorial review before a public launch; see `HUMAN_TODO.md`.

## Local development

Use a Node.js LTS version supported by the installed Astro version.

```sh
npm ci
cp .env.example .env
npm run dev
```

Set the real canonical HTTPS origin with `SITE_URL`. Keep public newsletter and analytics variables empty until their services are configured. All integration variables are build-time settings. `PUBLIC_` variables become visible in browser output and must never contain API keys.

```sh
npm run check          # Astro and TypeScript diagnostics
npm run lint           # ESLint
npm run check:contrast # Required token contrast checks
npm run build          # Contrast checks, static build, then Pagefind
npm run check:site     # Generated-site integrity checks
npm run preview       # Serve the completed dist/ build
npm run format        # Prettier
```

Pagefind is generated after production builds. Use `npm run build` followed by `npm run preview` to test search locally; the index is not generated by the dev server alone.

## Project layout

- `src/site.config.ts`: site identity, domain, tagline, and feature flags.
- `src/content.config.ts`: validated article and media schemas.
- `src/content/blog/`: educational MDX articles with topic, language, dates, takeaways, and references.
- `src/content/media/`: marked sample podcast and video metadata.
- `src/components/`, `src/layouts/`: shared page building blocks.
- `src/pages/`: article routes, topic hubs, reading paths, support and policy pages, feeds, and search.
- `src/styles/`: supplied color tokens and logical-property CSS.
- `scripts/`: project checks.
- `deploy/`: optional Nginx configuration and safe rsync deployment script.
- `docs/DEPLOY.md`: Cloudflare Pages and VPS deployment instructions, including HTTPS.
- `AGENTS.md`, `DECISIONS.md`, `HUMAN_TODO.md`: working rules, chosen defaults, and human-owned launch work.

## Content and privacy

Articles are educational, not a diagnosis or treatment service. Do not invent credentials, statistics, research, review history, crisis phone numbers, contact details, or audience claims. Add human-owned details to `HUMAN_TODO.md` until verified. Every article includes takeaways, author attribution, dates, references, and an educational disclaimer.

The site has no accounts, comments, database, or application backend. Newsletter forms submit directly to the configured provider; enable provider-side double opt-in and test its exact field mapping. Analytics load only when configured. Fonts are the system Arial stack, with no font downloads.

`features.media` defaults to false. When disabled, the Listen & Watch route, navigation entry, and home teaser are not generated. When enabled, media examples remain explicitly marked as samples until replaced with real material. YouTube embeds require a reader click before loading the third-party player.

For a production release, complete the human review checklist, run the project checks, and follow [deployment instructions](docs/DEPLOY.md). The attached user brief ends mid-sentence and omits its referenced implementation plan; implementation defaults are recorded in `DECISIONS.md`.
